## Scripts and completion (L10.GP.05)

- **Rescue objective:** none in ENG1's VORTEX code. Completion is gated only by the boss defeat; the "rescue Meg" story beat (LEAD) is not a gameplay condition.
- Checkpoints: none (one start); death → `HERO_Die` → restart at start 0, game over when lives reach 0 (`checkpoints.md`).
- Completion: timer 0x7028c runs out → `LVL_TickVortex` 0x44240 → `HERO_RequestLevelEnd` → `HERO_SetEndSequence` → opcode −9 → gs+3 = 0x31 → TITLE tally 0xd2 → post-tally FMV 0xf (Herculean) or 0x1b (Medium) → ending 0xcd → 0xcf (`progression.md`, S6.05).
- The ending passwords (23 Medium, 35 Herculean; result 12) do not play the ending: they show LEV12.TGA and return to the main menu (runtime, L10.TR.07 progress). The ending screens and credits need a played VORTEX defeat.
