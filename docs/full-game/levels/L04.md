## Traversal (L04.GP.02)

- Stairs and background routes: generic hero code on the attribute cells (above); the collision previews show where each attribute lies.
- **Cracks** 0x46 ×3 (`LVL_CrackUpdate` 0xfa00, as in FOREST): ground slam (attack bit 0x20) while standing on it opens it.
- **Multi-part structures** 0x49 ×8 (0x36150 / 0x361a0): parts (child list +0x120) rise to a rest height and then act; hit points 50 (digest). Collapsing structure / falling debris is a LEAD until a played run shows it.
- **Carried prop** 0x04 at x 17608 (0x14790 / 0x14850): follows the hero and changes with the carry states 0x2f/0x30 (0x6ef98), sfx 0x4151 (LEAD: an object the hero carries).
- Secrets: the letters and item-bit pickups in the generated table.

## Rescues, destruction and pickups (L04.GP.04)

- **Citizen rescues** (VERIFIED-STATIC, snow citizen `HERO_ThsnowUpdate` 0x33990 as the pattern): one kind per disaster bank: snow 0x2a ×4, earthquake 0x2b ×3, flood 0x2c ×3, flash-fire 0x28 ×3, charred 0x2d/0x3f/0x40, plus 0x33/0x34/0x44 and the food vendors 0x39–0x3b (code). The citizen calls for help (sfx 0x5140 every 90–149 ticks while the hero is within 32 z). Rescue needs no button: hero within 128 x and ±8 z, not yet rescued (+0x97). On rescue: countdown sparkle kind 0x4a, sparkle child 0xa001, sfx 0x4012, anim set 7; the citizen leaves (sfx 0x5941/0x5942).
- **Gauge event:** 0x48 at x 6145 acts only when counter 0x6ffda = 9; the THEBES tick 0x33720 shows the gauge in x 0x1510–0x1780, y > 0x440 while 0x6ffda < 8 (LEAD: the rescue count).
- **Scoring:** the rescue tally is TITLE-side (`progression.md`).
- **Destruction:** cracks and the 0x49 structures above.
- **Streaming:** class-0x1000 triggers request and free the Thebian banks along the route (e.g. 36/21 at x 576–640, freeing 27/23/36 at 2112).

## Substage and progression (L04.GP.05)

- **No substage mechanism** in this build (L04.RE.03, byte-store scan of every game-state reference): the "Part 2" password (16) is another table index with the same result (level 5). Which start it uses is part of play session 13.
- Death: `HERO_Die` → restart at gs+2 (the last Hermes marker).
- Completion: end flag 0x72170 → `HERO_SetEndSequence` → opcode −9 → gs+3 = 0x31 → TITLE tally → ENGINE1 HYDRA (ID 6) (`progression.md`). The completion trigger's location in THEBES is open (play session 12).
