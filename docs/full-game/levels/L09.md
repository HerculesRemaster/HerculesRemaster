- **Route choice:** at the end of track 0 (columns 230–239), lane rows 2–5 → track 1 and rows 6–9 → track 2 (codes 1/2). Tracks 1 and 2 then switch on to 3 and 4 (codes 3/4, columns 137–149).
- The two routes stay separate to the end. Completion x is 29696 and the no-jump zone is x ≥ 28928 on sections 3–4.
- **Track 0 layers:** block 0 has gaps that block 5 (height 4) covers. These are the drop points to watch for the River Styx falls (L09.RE.05; the no-input run dies twice at a fixed spot, L09.TR.06).

### Lanes and camera (VERIFIED-STATIC)

- Section → spline: 0 → 4, 1 → 0, 2 → 1, 3 → 2, 4 → 3 (`chase.md`).
- Splines 0, 1, 2 and 4 have a z centre of 768, half-width 96 and y 196. Spline 3 (section 4 = track 4) has half-width 0, so the lane is locked; whether that is the chariot ride is a LEAD (ride target speed 1.0, `chase.md`).
- The camera term is 0 everywhere except spline 2, which reaches 7.
- Floor clamp: y ≤ 200 only with cheats (gs+0x30 & 7). Without cheats, falling below the floor kills the hero.

### Completion (GP.05)

The shared end object (`LVL_EndObjectUpdate` 0x16320) starts the ride (state 10). At the level's completion x, `HERO_LevelComplete` 0x19c20 → state 9 → gs+3 = 0x31 → TITLE tally → gs[0] + 1 (`progression.md`). Respawn: `HERO_Die` 0x19a30 → gs+1 = gs+2 (restart section set by the Pegasus checkpoints), one life lost unless gs+0x30 & 8.
