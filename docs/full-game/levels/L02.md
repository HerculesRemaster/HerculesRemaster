# L02 Hero's Gauntlet (GAUNTLET, level ID 2, ENG3)

Specification for art/timing integration and coverage. The runner rules shared by L02/L07/L09 are in `docs/full-game/gameplay/chase.md` and are not repeated here. The data comes from `extracted/full-game/levels/GAUNTLET/level.json` (`tools/level/eng3_decode.py`) and `extracted/meta/full-game/L02-types.json` (`tools/level/eng3_types.py`). The formats are in `docs/full-game/eng3-format.md` and `eng3-tables.md`.

## Layout (L02.GP.01)

### Tracks and branch topology (VERIFIED-STATIC)

The map has 11 tracks (track table hdr+0x30). Each track is 128 columns × 128 units = 16384 units long, and is built from 4 blocks of 12 rows stacked at heights 0/4/8/12.

| track | parent | branch column | blocks | spawns | children (visible tracks) |
|---|---|---|---|---|---|
| 0 | root | – | 1, 0, 2, 3 | 105 | 1, 2 |
| 1 | 0 | 117 | 4–7 | 82 | 3, 4 |
| 2 | 0 | 117 | 8–11 | 67 | 5, 6 |
| 3 | 1 | 117 | 12–15 | 80 | 7 |
| 4 | 1 | 117 | 16–19 | 72 | 8 |
| 5 | 2 | 117 | 20–23 | 60 | 9 |
| 6 | 2 | 117 | 24–27 | 82 | 10 |
| 7–10 | 3–6 | 127 | 28–31 (shared) | 76 each | – |

The start records (section = track) are: start 0 at x 32 on track 0, then starts 1–7 at x 512 on tracks 0–6.

### Crossroads (VERIFIED-STATIC; runtime check pending, L02.TR.04)

- **Mechanism:** each tick, the hero's cell attribute code is looked up in config 0x3b900 +0x44. Code n (1–0x20) moves the hero to track n (`LVL_TriggerCode` 0x22b30 → `LVL_SetObjectTrack` 0x22620). x is rebased by branch column × 128, and the camera follows.
- **Two lane-based choices on every route:**
  - At the end of track 0 (columns 118–127): lane rows 0–5 → track 1, rows 6–11 → track 2.
  - At the end of track 1: rows 0–5 → 3, rows 6–11 → 4. At the end of track 2: rows 0–5 → 5, rows 6–11 → 6.
- **Forced continuation:** tracks 3–6 continue to 7–10 through column 127, rows 5–6.
- **Rejoin:** tracks 7–10 use the same blocks 28–31, so all four routes end on the same geometry, each with its own spawn list.
- No button is read. The branch is whichever lane half the hero is in when crossing the trigger columns.

### Lanes, surfaces, camera (VERIFIED-STATIC)

- **Lanes:** each block has 12 depth rows. Every cell carries a collision profile (bits 1–10, which also select the render mesh), a light zone (bits 11–23) with the attribute/trigger code, a mirror bit and a signed height (`eng3-format.md`).
- **Lane limits:** `LVL_TrackSpline` 0x1b650 (`HERO_Tick` lane clamp) on spline = current section (`chase.md`: GAUNTLET section n → spline n for n = 0–7, sections 8–10 → spline 7). There are 8 splines.
  - The z centre is about 768 (0x300) everywhere.
  - The normal half-width is 42. Wide stretches have half-width 180–200 (spline 2 at x 3747–4473, 5919–6681 and 11249–11833; also splines 4, 5, 6 and 7). There the camera term goes 40 → 70.
- **Camera:** height 0x40620 = 0xe8 − spline camera term, so 232 normally and 162 on the wide stretches. Follow distance and Up/Down targets are in `chase.md` (0x140 normal, 0x168 Up, 0xf0 Down).
- The pond/platform surfaces are among the cell attribute codes (`eng3-tables.md` attr table: GAUNTLET records 1–21). Their naming waits on the kind/handler work (L02.RE.02, L02.GP.03).

### Objects (summary; the detail goes in GP.03–GP.05)

There are 852 placed spawns across the 11 tracks. 326 of them are type 6, the HERCULES letters and pickups drawn from the LETTERS/XTRA_DB1/HERCULES banks. The kind → handler → bank table is `L02-types.json`.

## Runner parameters (GP.02)

The runner model is shared (`docs/full-game/gameplay/chase.md`): forced run, target speed 10.0 (0x38038), UP 16.0, DOWN −4.0/−6.0, lane step ±4.0 z per tick, jump vy 11.625. The dash (winged sandals: hero+0xee = 0x56, 0x3fb20 = 1, state 8) runs at 0x37fe8 and ignores codes 0x22/0x26/0x32/0x36. Branches are taken by lane (Layout). The values this level sets (`chase.md` per-level table, VERIFIED-STATIC) are:

| parameter | value |
|---|---|
| section → spline | n→n (sections 0–7 → splines 0–7, 8–10 → 7) |
| obstacle probe distance | x + 64, z ± 4 |
| side clamps (x < 768) | sections 1–6 |
| lane clamp to the alternative spline | – |
| water level 0x410e0 (speed /2, SFX) | 481 |
| landing tolerance 0x431e0 | 8 |
| ride target speed | 1.0 |
| no-jump zone | x ≥ 14720, sections 7–10 |
| completion x | 15360 |
| floor clamp (gs+0x30 & 7) | 512 (always) |

### Completion (GP.05)

The shared end object (`LVL_EndObjectUpdate` 0x16320) starts the ride (state 10). At the level's completion x, `HERO_LevelComplete` 0x19c20 → state 9 → gs+3 = 0x31 → TITLE tally → gs[0] + 1 (`progression.md`). Respawn: `HERO_Die` 0x19a30 → gs+1 = gs+2 (restart section set by the Pegasus checkpoints), one life lost unless gs+0x30 & 8.
