## God rescues (L08.GP.04)

- Gods are map kinds: 0x2c Aphrodite (bank 53, x 5921), 0x2d Apollo (54, x 15458), 0x2e Ares (55, x 20387), 0x2f Athena (56, x 20963), 0x30 Bacchus (57, x 25250); Zeus 0x45 (61, x 29059).
- `HERO_GodSpawn` 0x3abd0: z + 12; Bacchus and Zeus face left; state 0x35.
- `HERO_GodUpdate` 0x3ac80: in state 0x35, hero contact (body box) → sfx 0x627b, anim 1, state 0x2d → state 2; the god flies off at +6.0 x / −6.0 y per tick with sparkles (0x3c490) and is freed 400 units above the hero.
- Reward / persistence: no score write in these handlers; the tally is TITLE-side (`progression.md`). Rescues do **not** gate completion: no code checks them.
- Open: how the god banks (53–57, 61) are loaded; no ENG1 code requests them (L08.RE.05 progress 2).

## Scripts and completion (L08.GP.05)

- Checkpoints: the three floating markers set gs+2 (`checkpoints.md`).
- Pickups: the 0x20xx kinds in the generated table (letters 0x200b ×8, extra life 0x2012, …).
- Completion: Zeus (`HERO_ZeusUpdate` 0x3adc0): hero contact in state 0x35 → sfx 0x627b, state 0x2d, timer 120; fade-out at 16 ticks left; at 0 gs+3 = 0x31 directly (no `HERO_SetEndSequence`). TITLE: Beginner → ending 0xcd (the Beginner endpoint, S6.06); Medium/Herculean → FMV 0x19 → gs[0] = 10 → card SEQ8 → **ENGINE3** TORMENT (ID 10) (`progression.md`, S6.05).
- Death: flight death (`flight.md`) → gs+3 = 0x21 (restart at the restart index) or 0x22 (game over).
