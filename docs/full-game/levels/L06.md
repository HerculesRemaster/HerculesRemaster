## Scripts and progression (L06.GP.05)

- Props/pickups: none in the map; drops come from skeletons and broken columns (item 0x289).
- Checkpoints: none in the map; restart index stays 0 (`checkpoints.md`).
- Completion: `HERO_RequestLevelEnd` → `HERO_SetEndSequence` → opcode −9 → gs+3 = 0x31 → TITLE tally 0xd2 → FMV 0x11 → gs[0] = 8 → card SEQ3 → **ENGINE3** CYCLOPS (ID 8) (`progression.md`, ENG1 → ENG3 switch).
- Death: `HERO_Die` → restart at start 0; whether Medusa's health and the skeleton counter reset is open (L06.TR.06).
