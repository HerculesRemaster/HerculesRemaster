## Hero movement (L05.GP.02)

Normal ENG1 platforming (`docs/gameplay-spec.md`); `HERO_Init` has no HYDRA branch. Only the camera differs: it follows the arc records, so screen-left/right map to movement along the arc. Whether the pad mapping rotates with the arc is open (needs the arena play session).

## Hydra encounter (L05.GP.03)

Full template entry: `docs/full-game/gameplay/encounters.md` § Hydra. Summary (VERIFIED-STATIC):

| field | value |
|---|---|
| entry / spawn | no trigger: `LVL_InitLevelActors` 0x1fd20 → `LVL_InitHydra` 0x1ac10 at section start; sfx 0x180/0x193; boss gauge started (5); difficulty table 0x56048 / 0x560e0 / 0x56168 → 0x6f3cc |
| drawing | necks (kind 0x29) and heads (0x2d) are multi-part T28 models animated by `ANIM_StepModelParts` 0x28aa0 (part table 0x56240); bank 79 BOSS\HYDRA sprites are effects and the cut head 0x30 |
| structure | 8 neck/head slots; head phases (0x6f44c): 0 → slot 7; 1 → slots 3, 1, 5; phases 4–7 replace the cut head and add slots 2, 4, 0, 6 |
| attacks | strike and contact in neck states 3/4 with extension +0x49 ≥ 0x26: `HERO_RequestDamage(head, 0x22)` → 10/25/30 |
| vulnerable window | cut when attack box 2 is near the neck, +0x49 in 0x26..0x38, attack bits & 0x18 (`HERO_HydraCutHead` 0x1d6c0) |
| defeat | 8 cuts (counter 0x6efb8, gauge 32 per cut) → 0x72014 → `LVL_TickHydra` 0x1ae00 explosions (sequence 0x6f3e0) → end flag 0x72170 |
| difficulty | only the drop stream table (0x56048 / 0x560e0 / 0x56168) |

Hazards around the fight: tumbling debris 0x2f (`HERO_HydraDebrisUpdate` 0x1e3f0, bounces at y 0x3d8, sfx 0x188–0x18a) and falling boulders 0x33 (`HERO_HydraBoulderUpdate` 0x1e600: `HERO_RequestDamage(rock, 0)` → 5/12/15 without recoil). Stage controller 0x2c (`HERO_HydraStageTick` 0x1ed30, stages 0x6f4bc 0..5, table 0x589f8, sfx 0x192).

## Scripts (L05.GP.04)

- No trigger cells other than the wall attribute; no checkpoint, pickup or letter spawns in the map. Drops come from the Hydra's drop stream.
- Defeat → completion: end flag 0x72170 → `HERO_SetEndSequence` 0x19160 → end script 0x54b50 opcode −9 → gs+3 = 0x31 (`checkpoints.md`).

## Death, retry and completion (L05.GP.05)

- Death: `HERO_Die` 0x18f60 (lives − 1, restart at start gs+2 = 0; HYDRA sets no other restart index). Whether the Hydra's slots and cut counter reset on a retry is open (L05.TR.06).
- Completion: gs+3 = 0x31 → TITLE tally 0xd2 → post-tally FMV 0xe → gs[0] += 1 → card SEQ2 → ENGINE1 MEDUSA (ID 7) (`progression.md`).

## Difficulty (L05.GP.06)

`extracted/meta/full-game/tuning.json`: `eng1.hero_damage` (0x55348), `eng1.hydra_tables` (0x56048 / 0x560e0 / 0x56168), and the per-kind rows `eng1.L05.kind….damage`.
