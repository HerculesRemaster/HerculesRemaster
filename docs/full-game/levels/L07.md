# L07 Cyclops Attack (CYCLOPS, level ID 8, ENG3)

Specification for art/timing integration and coverage. The shared runner rules are in `docs/full-game/gameplay/chase.md`. The data comes from `extracted/full-game/levels/CYCLOPS/level.json` and `extracted/meta/full-game/L07-types.json`. The formats are in `docs/full-game/eng3-format.md` and `eng3-tables.md`.

## Layout (L07.GP.01)

### Tracks (VERIFIED-STATIC)

The map has 4 tracks in a chain. Each is about 256 columns × 128 units, and each uses 4 blocks stacked at heights 0/4/8/12.

| track | parent | branch column | blocks | spawns |
|---|---|---|---|---|
| 0 | root | – | 3, 2, 1, 0 | 196 |
| 1 | 0 | 255 | 7, 6, 5, 4 | 177 |
| 2 | 1 | 254 | 11, 10, 9, 8 | 165 |
| 3 | 2 | 254 | 15, 14, 13, 12 | 0 |

- **Forced switches:** code 1 (track 0, column 255, rows 4–7) and code 2 (track 1, column 254, rows 3–6), handled by `LVL_TriggerCode` 0x22b30. No lane choice.
- **Starts:** starts 0–3 at x 0, y 448 on tracks 0, 0, 1, 2; starts 4 and 5 at x 1920 on track 0.
- **End:** completion x 30592; no-jump zone x ≥ 29824 on section 2 (`chase.md`).

### Street and alternate lane (VERIFIED-STATIC data; meaning LEAD)

There are 9 splines in triples per section: (0, 1, 2), (3, 4, 5), (6, 7, 8). `HERO_Tick` uses section 0 → (0, 1), 1 → (3, 4), 2 → (6, 7) as primary and alternative. It clamps the hero to the alternative spline only while 0x1400001 ≤ y ≤ 0x1c00000 (320–448; flag 0x3fb2c).

| | splines | z centre | half-width | camera term |
|---|---|---|---|---|
| primary | 0, 3, 6 | 520–862 | 32–284 | 0/30/40/60/70 |
| alternative | 1, 4, 7 | 454–958 | 0–248 | 0/120 |
| third (consumers 0x5760/0x5b40, open) | 2, 5, 8 | 516–904 | 56–224 | 0; y 96 |

The alternative splines are narrow, shifted in z and raise the camera term to 120. That fits stairs or raised walkways (the walkthrough's stairs), but the identification is a LEAD until L07.TR.04 takes them at runtime.

### Cyclops

`LVL_CyclopsTick` 0x1880 runs only on level 8. It drives the Cyclops object 0x3fb0c (animation states 0x41–0x45, camera shake 0x405fc). Its states and attacks are L07.RE.04 / GP.04 (see "Cyclops (L07)" below).

## Cyclops (L07)

The data is in `analysis/exports/full-game/eng3_cyclops.json`. It is VERIFIED-STATIC (ENG3 decompilation). Frame identities are VISUAL, from the decoded banks. Trigger columns come from the MAP_PSX.BIN zone and attr tables, decoded with the `LVL_CellAttribute` 0x1b4a0 rule. Frame numbers are anim-script values (obj+0x34). Each script entry {frame, t} shows for t+1 ticks.

### Creation and movement

- **Creation:** `LVL_StartSection` → 0x1b9c0 → 0x1870 (gs+0 = 8) → 0x3290.
  - 0x3290 creates two actors: kind 0x3c (skyline) and kind 0x29 (the Cyclops, pointer 0x3fb0c), both at `LVL_NewActor`(0xa20000, 0x1c60000, 0).
  - It then sets the Cyclops x = hero x + 0x6800000 (1664), its track = the hero track, state 0x42 and script 4.
  - The Cyclops is not on the map. It is created again on every section start and restart.
  - The spawn handler 0x3200 sets: shake counter +0xcc = 0x50, foot toggle +0xd8 = 1, throw arm +0xac = 1, +0x11e = 0.
- **Movement:** the Cyclops is locked to the camera.
  - Each tick x += (0x3fb94 − 0x3fb98) << 16. That is the camera x delta (0x405e0, sampled in `LVL_UpdateObjects`). A delta < −0x180 counts as 0.
  - Above 0x7f7fffff, x wraps to 0 on the next track.
  - y 0x1c60000 (454) and z 0 are fixed. No spline is used.
  - So the Cyclops stays about 1664 ahead of the hero, in the background, and never reaches the hero.
- **Banks:** the script list is at 0x33800. +0x22 = 7 (CYEND) while script 1 (0x33100) or script 3 (0x331b0) runs; otherwise it is 5 (CYCLOPS).
- **Kind 0x3c (skyline):** the PEOPLE frame 240 backdrop (256×32, a row of city buildings).
  - Handlers 0x4b60 / 0x4bc0.
  - It moves with the same camera delta (here the cut-off is −0x80).

### Triggers

`HERO_SurfaceTriggers` 0x17ae0 runs every tick at the hero position. While the hero is inside a trigger column, the script restarts each tick: the Cyclops holds the first frame of the move and plays it after the hero leaves the column. Column c covers x c·128+64 to c·128+191. Rows 3–8 cover the whole street.

| code | effect | columns |
|---|---|---|
| 0x57 | stomp: state 0x41, script 0 (+0xd8 = 0) or 2 (+0xd8 = 1) | T0 4, 24, 38, 65, 130, 151 (alternative block: 38, 187, 224); T1 1, 53, 105, 132, 232; T2 14, 168, 218 |
| 0x53 | state 0x42 (stops the shake, re-arms the throw) | T0 23, 37, 78, 150 (alternative: 37, 51, 164, 202, 238); T1 13, 68, 121, 144, 249; T2 27, 100, 184, 231 |
| 0x5b | throw: state 0x43, script 8 | T0 alternative 56; T1 202; T2 36, 55, 143, 195 |
| 0x54 | state 0x44, script 5 | no map cell (attr record 8 is unused) |

- **Idle actions** (no spawns):
  - script 3: CYEND 16–33, club smash with drawn rubble (SFX 0x20b, 0x200–0x203), ~72 ticks;
  - script 6: CYCLOPS 134–148, club shake;
  - script 7: CYCLOPS 96–114, crouch-and-flex roar.
  - Scripts 6 and 7 run CALL 3 = 0x6f70, which plays the roar SFX 0x211, 0x212, 0x22c, 0x22d in turn.
- **Camera shake:** runs while +0x11e is 1 or 2 and +0xcc ≠ 0.
  - Each tick takes three steps of a saw-tooth: 0x405fc = +0xe0, then +0xe0 += 0x20000, wrapping from above 0x80000 to −0x80000.
  - +0xcc counts down from 0x50 (80 ticks).

### Hazards and damage

- **The Cyclops itself** has no hit box. 0x3610 never calls `HERO_Hit`, so there is no catch and no instant death.
- **Thrown rock, kind 0x30** (0x3340 / 0x33f0):
  - It is model 0x21 with a model shadow 0x2002.
  - It flies toward the hero at x −0x200000 (32) per tick, with gravity 0xf000. z is forced to 0x400000 (64).
  - Hit test while dx < 0x578: −0x80 < dx < 0x80 and |dz| < 0x36. On a hit: hit code 2 → `HERO_Hit` 0x19200 (skipped while the hero is in state 5).
  - Damage is T3 = **25 / 30 / 40** (Beginner / Medium / Herculean). Knock-back: x −1.0, z 3.0 away.
  - On its first bounce: SFX 0xe206, and it breaks into 4 shards (kind 0x4002). Speed >>= 3 per bounce.
- **Column signal:** the toppling columns 0x2b/0x2e (`LVL_CycColumnFwdTick` 0x1fe0, `LVL_CycColumnBackTick` 0x2ac0) process nothing until a stomp impact (Cyclops +0x11e = 1) happens while they are alive.
  - The impact latches the column (+0x30 = 1).
  - The column then topples when hero dx < (byte + 7)·128 and hits with code 2 (25/30/40).
- **Difficulty:** gs+0xe is not read anywhere in the Cyclops code. It acts only through the damage table 0x380a0.
- **Random values:** none in the controller (the idle action counter is deterministic). `RT_RandMod_slot` 0x1fab0 is used only for the shard offsets and the debris speeds.
- **Markers** (both use PEOPLE frames 284–290, tumbling stone wedges, script 0x37658):
  - **0x4002** (0x14d90 / 0x14f00): the rock's 4 shards. Freed 128 behind the hero.
  - **0x4003** (0x14fd0 / 0x15110): stone chunks from boulders 0x2a (8 each) and column pieces (6 each). Freed 32 behind the hero.
  - Both bounce through 0x1460 and never hit the hero.

### CYEND and the level end

- **CYEND is not an ending.** It is a second Cyclops bank, swapped in for script 1 (recovery, after a throw, and the hero-death gloat) and script 3 (the club-smash idle action, and state 0x48).
- **Completion** does not involve the Cyclops:
  1. The end object `LVL_EndObjectUpdate` 0x16320 calls `HERO_LevelComplete` 0x19c20 once (flag 0x37b98) when hero x > 0x777fffff (30592).
  2. The hero enters state 9.
  3. `HERO_State09` 0x19cd0 fades the screen once the hero frame passes 0x1e (gs+0x1b30 = 4).
  4. When the hero script ends, it sets gs+3 = 0x31.
- The Cyclops keeps its current state throughout.

### Cross-traffic

- **Source:** all traffic is fixed map spawns from the track spawn lists, released by `LVL_SpawnStep` 0x1c430 as the drawn columns advance. There is no timer and no random schedule.
- **Activation** is by hero distance or by trigger codes:
  - boulders 0x2a: < 1024;
  - crossing chariots 0x2d: < 768;
  - oncoming chariots 0x2f: drive at the hero;
  - columns 0x2b/0x2e: armed by a stomp, then by distance;
  - bystanders 0x42: start running when reached;
  - flyers 0x3d/0x3e: < 768–2304;
  - opening columns 0x45: hero x > 256.
- **Crowd sources 0x3f** emit fleeing citizens 0x4033 at an interval, under the codes 0x6e/0x6f/0x70.
  - On the map: 0x6f at T1 25; 0x70 at T0 76, 245, T1 115, 125, 172, 246 and T2 62, 151, 209, 221.
  - 0x6e is not on the map.
- **Splines 2/5/8** (read by 0x5760 / 0x5b40) are the citizens' running path, not a Cyclops path.

### Completion (GP.05)

The shared end object (`LVL_EndObjectUpdate` 0x16320) starts the ride (state 10). At the level's completion x, `HERO_LevelComplete` 0x19c20 → state 9 → gs+3 = 0x31 → TITLE tally → gs[0] + 1 (`progression.md`). Respawn: `HERO_Die` 0x19a30 → gs+1 = gs+2 (restart section set by the Pegasus checkpoints), one life lost unless gs+0x30 & 8.
