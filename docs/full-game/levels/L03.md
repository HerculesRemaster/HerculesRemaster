## Traversal (L03.GP.02)

Only what differs from the ENG1 hero spec:

- **Background paths:** no FOREST-specific object; depth changes use the generic layer rule above. Which cells allow a switch is in the collision previews.
- **Tree climbing:** generic hero climbing on the cell collision profiles (S2); no level object.
- **Stone barriers** 0x4c ×6 (`LVL_BarrierUpdate` 0xa010): hit points +0xee; each punch accepted by the attack bits (~0x72168 & 0x5f) removes 1; a charged Power Punch (bit 2, charge 0x7082c > 200) or a projectile breaks it at once. Break: sfx 0xcf, debris `FUN_10009db0`, flag 0x6ef90.
- **Layer barriers** 0x4e ×4 (`LVL_LayerBarrierUpdate` 0xa490): the same on the hero's layer only; hit points reset to 50 when the hero is more than 160 units away.
- **Cracks** 0x4f ×2 (`LVL_CrackUpdate` 0xfa00): stand on it within 64 units and use the 0x20 attack bit (ground slam): dust 0x2027, collision box tables 0x52050/0x520a8 swap (opens the way).
- **Secrets:** item-bit pickups 0x201a..0x201d (one each) and the HERCULES letters 0x200b ×9.
- **Streaming:** class-0x1000 trigger kinds load/free banks along the route 120–180 units before the camera (`animation-coverage.json` `eng1_map_triggers`).

## Scripts and completion (L03.GP.05)

- Checkpoints: Hermes markers 0x400a..0x400f (above); touching an inactive one plays sfx 0x28 and sets gs+2 to its index (`checkpoints.md`). The Nessus trigger also sets gs+2 = 5.
- Pickups and letters: letters 0x200b ×9 (gs+0x1c bits), item bits 0x201a..0x201d, extra life 0x2012, and the other 0x20xx pickups in the generated table.
- Completion: Nessus defeat → 0x19240 end flag 0x72170 → `HERO_SetEndSequence` 0x19160 → end script 0x54b50 opcode −9 → gs+3 = 0x31 → TITLE tally 0xd2 → FMV 0xc → gs[0] += 1 (4 is forced to 5) → card SEQ1 → ENGINE1 THEBES (ID 5) (`progression.md`).
- Death: `HERO_Die` → restart at start gs+2.
