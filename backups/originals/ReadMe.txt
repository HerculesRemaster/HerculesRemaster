HERCULES - WIN95 VIDEOGAME

HOW TO LAUNCH THE GAME:

1. First, launch SETUP.BAT.

2. Double click HERCULES.EXE and it should work. If you receive an error message “Hercules is not
installed”. If you still see this error, try to click on HERC.REG. And try to open HERCULES.EXE.

If you have problems with video, use Alt+ENTER or windows key to switch from FULL SCREEN to WINDOW MODE. After that
you can use the Display menu to increase resolution to 640x480.

Music is not included but sound effects should work.
