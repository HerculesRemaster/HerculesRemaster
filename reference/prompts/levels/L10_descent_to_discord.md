# L10 — Descent to Discord

| Mục | Nội dung |
| --- | --- |
| Tên màn | **Descent to Discord** — "Kokytos · Tartarus · The Temple of Discord" |
| Vị trí trong game gốc | Passageway of Eternal Torment (âm phủ, boss cuối) |
| Kiểu màn | 3 phần: hồ băng (boss Ophiotaur) → hang âm phủ xanh ngọc (platforming khó) → đền Discord (boss Eris) |
| Bối cảnh | **Kokytos**: sông than khóc đóng băng, mặt người kẹt trong băng. **Tartarus**: vực âm phủ với thác xanh ngọc, tượng thần đổ, lồng treo xích. **Đền Discord**: đền cẩm thạch đen gân vàng lơ lửng trong khói tím |
| Ánh sáng | Xanh băng → xanh ngọc âm phủ → tím và vàng |
| Set piece | (1) Trượt trên băng, Ophiotaur trồi lên; (2) nhảy giữa lồng treo trên vực; (3) shade trôi xuyên tường; (4) Deimos & Phobos đánh đôi; (5) Eris 3 pha |
| Kẻ thù | Shade, Empousa, bóng gai Discord, Deimos & Phobos |
| Bẫy | Băng trơn, lửa xanh lục từ sàn, lồng rơi, sàn đền vỡ |
| Vật phẩm | Obol, ambrosia, sao Pleiades cuối cùng, mọi boon |
| Bảng màu | Xanh băng `#9FD3F2`, xanh ngọc âm phủ `#1FAE7A`, tím than `#4A2A5E`, vàng `#E2B34A` |
| Boss | [Ophiotaur](../bosses/07_ophiotaur.md) (B13, B14), [Eris](../bosses/08_eris_final.md) (B15, B16) |
| Style CGI tham khảo | *Frozen Ophiotaur Boss Battle* (chỉ lấy hang băng), *Hercules in the Emerald Underworld*, *Mythic Cavern Guardian*, *Hercules_ Golden Underworld Menu* (chỉ lấy dung nham và đá) |
