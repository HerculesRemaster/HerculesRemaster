# L02 — The Trials of Tiryns

| Mục | Nội dung |
| --- | --- |
| Tên màn | **The Trials of Tiryns** — "Run the Gauntlet" |
| Vị trí trong game gốc | Màn 2 Gauntlet: chuỗi bẫy, nhảy chính xác, đu xà |
| Kiểu màn | Side-scroller, nhiều tầng, thiên về bẫy |
| Bối cảnh | Thành Tiryns (nơi vua Eurystheus giao thử thách cho Heracles): tường đá khổng lồ kiểu cyclopean, cầu thang dốc, hành lang bẫy, cổng sư tử nhỏ |
| Thời gian / ánh sáng | Chiều nắng gắt, sau đó vào hành lang đuốc |
| Set piece | (1) Cầu thang dài có máy bắn đá lửa lăn xuống; (2) xà vàng xoay trên hố chông; (3) cột đổ dây chuyền; (4) cổng đầu sư tử phun lửa định kỳ |
| Kẻ thù | Chim Stymphalian, hình nộm cơ khí bằng gỗ và đồng |
| Bẫy | Đá lửa lăn, lưỡi rìu đung đưa, sàn sập, ống phun lửa |
| Vật phẩm | Obol, lông vũ Zephyr (tăng tốc), mảnh ostrakon đầu tiên |
| Bảng màu | Đá vôi xám ấm, vàng đồng, cam lửa, trời xanh |
| Style CGI tham khảo | *Hercules Leaps Through Flaming Temple Traps*, *Inverted Hercules on the Golden Trap Bar*, *Heroic Leap Beneath the Lion Gate* |
